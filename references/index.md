## 🧭 风格推荐路由逻辑

当用户未指定明确风格时，按以下维度进行推荐：

1. **硬核实操 / 极客编程 / AI 工具教程** ➡️ 优先推荐 `06` (赛博机能波点) 或 `01` (色块聚焦)
2. **长篇架构 / 方法论 / 深度认知拆解** ➡️ 优先推荐 `05` (东方呼吸竖排) 或 `04` (虚实线框衬底)
3. **成长思考 / 工作流联动 / 工具生态** ➡️ 优先推荐 `02` (灵动曲线穿插)
4. **独立开发心情 / 审美与生活 / 个人IP随笔** ➡️ 优先推荐 `03` (双字体碰撞)
5. **重磅突发 / 前沿技术颠覆 / 狂欢互动** ➡️ 优先推荐 `07` (故障切片抽离)
